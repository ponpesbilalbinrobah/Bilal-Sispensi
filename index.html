📖 Petunjuk Mudah: Cara Mendapatkan Web App URL di Google Apps Script (Klik untuk melihat)
  1. Buka file Code.gs di editor Google Apps Script spreadsheet Anda (Buka Spreadsheet > menu Ekstensi > Apps Script).
  2. Pastikan isi file Code.gs sudah diperbarui dengan kode terbaru dari folder proyek ini, lalu simpan (Ctrl+S).
  3. Klik tombol biru Deploy (Penerapan) di pojok kanan atas > pilih New deployment (Penerapan baru).
  4. Klik ikon gerigi ⚙️ di samping Select type > pilih Web app.
  5. Isi formulir:
    • Description: SisPensi API v2
    • Execute as: Me (Akun Google Anda)
    • Who has access: Anyone (Siapa saja)
  6. Klik Deploy, berikan izin akses akun Google jika diminta.
  7. Salin URL Web App yang berakhiran /exec dan tempelkan pada kolom input di atas, lalu klik Simpan & Hubungkan!
